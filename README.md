# NO RULES — B1.0 Preview 10

Visual/gameplay prototype containing the first 10 redesigned levels using the approved neon concept art as full-screen references.

Levels:
1. Key Problem
2. Tiny Maze
3. Color Splash
4. Zen Mode
5. Quiet Please
6. Wake the Lock
7. Monster Snack
8. Mirror Beam
9. Bright Circuit
10. Balloon Lift

The HELP/HINT button is always visible; the solution is never shown directly on the level screen. Hints open only when requested.

Build with GitHub Actions using `.github/workflows/build-apk.yml`.
